# Personal data this repo holds — the one list

This repo is public. This file is the only place that would list personal data
it holds on purpose, and it holds none: there are no entries below.

**The list is closed.** In a public repo a personal-data exception is the
principal's alone to grant, in his own words. A session never adds an entry on
its own judgement: it stops, asks him through the question device, and writes
his answer here only when it is a grant. A session that finds personal data in
this repo has found a breach, not an oversight to document around.

Each entry, when one is granted, is a `## PDn — title` section giving the data,
why it is held, how it was granted, and the files it may stand in
(`../atelier/docs/PERSONAL-DATA.md` shows the shape).
